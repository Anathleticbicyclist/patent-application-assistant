# 权利要求书

1. 一种电池热失控预警方法，其特征在于，包括：
S1、以预设采样率采集电池模组的温度信号与电压信号；
S2、对所述温度信号滑窗分段，在每个滑窗内提取温升斜率；
S3、当所述温升斜率超过预设阈值时，在预设时间窗口内再次采集所述温度信号与所述电压信号，若再次满足预设条件则输出告警。
2. 根据权利要求1所述的方法，其特征在于，所述预设采样率为50-200Hz。
3. 根据权利要求1所述的方法，其特征在于，所述预设时间窗口为0.5-5s。
4. 根据权利要求2所述的方法，其特征在于，所述温度信号经带通滤波处理后再提取温升斜率。
5. 根据权利要求1所述的方法，其特征在于，所述再次满足预设条件包括：再次提取的温升斜率仍大于所述预设阈值，且所述电压信号的下降幅度小于预设值。
6. 一种电池热失控预警装置，包括处理器和存储器，其特征在于，所述处理器执行所述存储器中的程序时实现权利要求1至5任一项所述的方法。

# 说明书

## 技术领域
本发明涉及电池管理技术领域，具体涉及一种基于温升斜率与二次确认的电池热失控预警方法及装置。

## 背景技术
现有的电池热失控预警方案多采用绝对温度阈值判断：当采集到的温度超过固定阈值时输出告警。该方式存在两个问题：其一，热失控早期温升绝对幅度很小，固定阈值往往要等到热失控已经发生才被触发，预警窗口过短；其二，单次采样易受电磁干扰与传感器瞬时异常影响，容易产生误报，导致告警被运维人员忽视。

## 发明内容
本发明要解决的技术问题是：如何在温度绝对值尚未明显变化时识别热失控趋势，并抑制单次采样异常造成的误报。

为解决上述技术问题，本发明提供一种电池热失控预警方法，以温升斜率捕捉早期趋势，并在触发后于预设时间窗口内二次采集确认。

第一方面，本发明提供一种电池热失控预警方法，包括：以预设采样率采集电池模组的温度信号与电压信号；对所述温度信号滑窗分段并提取温升斜率；当温升斜率超过预设阈值时，在预设时间窗口内再次采集温度信号与电压信号，若再次满足预设条件则输出告警。

第二方面，本发明提供一种电池热失控预警装置，包括处理器和存储器，处理器执行存储器中的程序时实现上述方法。

与现有技术相比，本发明的有益效果在于：其一，以斜率而非绝对温度作为判据，可在温度绝对值变化尚小时触发初判，提前预警时点；其二，触发后在窗口内二次确认，把单次采样异常与真实热失控区分开，降低误报率。

## 具体实施方式
下面结合附图对本发明的具体实施方式作详细说明。以下实施例用于说明本发明，但不用于限制本发明的范围。

实施例1
本实施例提供一种电池热失控预警方法，执行主体为电池管理系统中的控制单元。

S1、以预设采样率采集电池模组的温度信号与电压信号。本实施例中预设采样率取100Hz，即每10ms采集一次；温度信号由贴设于各电芯表面的热敏电阻采集，电压信号由电压采样电路采集。

S2、对温度信号滑窗分段并提取温升斜率。本实施例中滑窗长度取2s、步长取0.5s；在每一滑窗内对温度采样序列作最小二乘线性拟合，取拟合直线的斜率作为该滑窗的温升斜率，单位为℃/s。

S3、当温升斜率超过预设阈值时二次确认。本实施例中预设阈值取0.5℃/s；一旦某滑窗的温升斜率超过0.5℃/s，则在预设时间窗口（取1s）内以相同采样率再次采集，若第二次计算的温升斜率仍大于0.5℃/s，且电压信号未出现骤降，则判定为真实热失控并输出告警；若第二次计算的温升斜率回落至阈值以下，则判定为瞬时干扰，不输出告警。

实施例2
本实施例与实施例1的区别在于参数取值：预设采样率取200Hz，滑窗长度取1s，预设阈值取0.8℃/s，预设时间窗口取3s。其余步骤与实施例1相同。该参数组合适用于热惯性较大的大容量储能电池模组。

实施例3
本实施例与实施例1的区别在于：在提取温升斜率之前，先对温度信号作0.1-10Hz带通滤波，以抑制工频干扰与开关噪声；其余步骤与实施例1相同。

以上所述仅为本发明的较佳实施例，并不用于限制本发明。凡在本发明的精神和原则之内所作的等同替换、改进等，均应包含在本发明的保护范围之内。

# 摘要
本发明公开一种电池热失控预警方法及装置。该方法以预设采样率采集电池模组的温度信号与电压信号，对温度信号滑窗分段并提取温升斜率，当温升斜率超过预设阈值时在预设时间窗口内再次采集并二次确认，满足条件则输出告警。本发明可在温度绝对值变化尚不明显时捕捉热失控趋势，并通过二次确认抑制瞬时干扰引起的误报。
