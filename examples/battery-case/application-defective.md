# 权利要求书

1. 一种电池热失控预警方法，其特征在于，包括：
S1、以预设采样率采集电池模组的温度信号与电压信号；
S2、对所述温度信号滑窗分段并提取温升斜率；
S3、当温升斜率超过预设阈值时，在预设时间窗口内再次采集信号，若再次满足预设条件则输出告警。
2. 根据权利要求1所述的方法，其特征在于，所述预设采样率为50-200Hz。
3. 根据权利要求1所述的方法，其特征在于，所述预设时间窗口为0.5-5s。
4. 根据权利要求1至3任一项所述的方法，其特征在于，所述温度信号经带通滤波处理。
5. 一种电池热失控预警装置，包括处理器和存储器，所述处理器执行时实现权利要求1所述的方法。
