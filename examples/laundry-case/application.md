# 权利要求书

1. 一种多筒洗衣机的协同控制方法，其特征在于，包括：
S1、检测大筒的偏心量与小筒的偏心量；
S2、根据所述大筒的偏心量与所述小筒的偏心量，判断是否满足同时脱水条件；
S3、当不满足所述同时脱水条件时，按照协同控制程序执行错峰脱水或反向配重；
S4、执行所述错峰脱水或所述反向配重后，控制所述大筒与所述小筒完成脱水。

2. 根据权利要求1所述的方法，其特征在于，洗涤进水阶段，分水阀按大筒洗涤水路与小筒洗涤水路分时切换，漂洗阶段所述分水阀切换至喷淋臂水路，所述大筒的洗涤水与所述小筒的洗涤水在分排水管路中互不串水。

3. 根据权利要求1所述的方法，其特征在于，所述同时脱水条件为：所述大筒的偏心量与所述小筒的偏心量均小于预设偏心量阈值，所述预设偏心量阈值为80-120g·mm；所述错峰脱水的错峰时间窗为8-15s。

4. 根据权利要求1所述的方法，其特征在于，所述反向配重包括：控制所述小筒的直驱电机相对所述大筒的直驱电机反向转动，使所述小筒的偏心相位与所述大筒的偏心相位相差180°。

5. 一种多筒洗涤设备，其特征在于，包括大筒、小筒、分水阀、分排水管路、共用减振组件和独立悬挂；所述大筒包括大筒内筒与大筒外桶，所述小筒包括小筒内筒与小筒外桶；所述分水阀的进水口与外部进水管路连通，所述分水阀的两个出水口分别与所述大筒外桶和所述小筒外桶连通；所述分排水管路包括大筒排水管与小筒排水管，所述大筒排水管的上端与所述大筒外桶的底部连通，所述小筒排水管的上端与所述小筒外桶的底部连通，所述大筒排水管与所述小筒排水管相互隔离且互不串水；所述大筒通过所述独立悬挂悬挂于机壳内的安装梁上，所述小筒通过所述独立悬挂悬挂于所述大筒外桶的下方；所述共用减振组件固定于所述机壳与所述独立悬挂之间，所述共用减振组件同时连接所述大筒的悬挂件与所述小筒的悬挂件。

6. 根据权利要求5所述的多筒洗涤设备，其特征在于，所述共用减振组件包括减振弹簧、阻尼器与平衡配重块，所述减振弹簧的上端固定于所述机壳，所述减振弹簧的下端连接所述独立悬挂，所述阻尼器的两端分别铰接所述机壳与所述独立悬挂，所述平衡配重块滑动设置于所述共用减振组件的横向导轨上。

7. 根据权利要求5所述的多筒洗涤设备，其特征在于，所述独立悬挂包括大筒悬挂吊杆与小筒悬挂吊杆，所述大筒悬挂吊杆的上端固定于所述机壳的顶部，所述大筒悬挂吊杆的下端与所述大筒外桶的外壁铰接，所述小筒悬挂吊杆的上端固定于所述大筒外桶的底部加强筋，所述小筒悬挂吊杆的下端与所述小筒外桶的外壁铰接。

8. 根据权利要求5所述的多筒洗涤设备，其特征在于，所述大筒内筒的内壁固定有提升筋，所述小筒内筒的内壁固定有提升筋，所述大筒外桶与所述小筒外桶的上部均固定有平衡环，所述大筒内筒与所述小筒内筒分别由直驱电机驱动转动，所述直驱电机与所述大筒内筒之间、所述直驱电机与所述小筒内筒之间分别设置有离合器。

# 说明书

## 技术领域
本发明涉及洗涤电器技术领域，具体涉及一种大筒洗涤外衣、小筒洗涤内衣的多筒洗衣机，以及该多筒洗衣机在分水、独立脱水工况下的共振抑制协同控制方法与设备。

## 背景技术
对比文件 CN________A（占位号，示例用，交付前须替换为真实检索到的对比文件公开号）公开了一种双筒洗衣机，两个洗涤筒共用一个机壳与一套进水排水管路。现有方案存在以下具体矛盾：其一，大筒与小筒同时脱水时，各自偏心转动产生的振动经共用外桶结构叠加，引起整机位移与共振；其二，由于两筒共用外桶结构，减振件不能简单串联布置，单筒减振方案移植到双筒之后减振效果下降；其三，洗涤进水与排水若共用同一管路，外衣洗涤水与内衣洗涤水存在串水风险，难以满足内衣单独洗涤的卫生要求。

## 发明内容
本发明要解决的技术问题是：两筒同时脱水时振动叠加导致整机位移与共振，且共用外桶结构不能简单串联减振；同时避免洗涤水分路与排水分路串水。

为解决上述技术问题，本发明提供一种多筒洗衣机的协同控制方法：先检测大筒与小筒各自的偏心量，判断是否满足同时脱水条件，不满足时按协同控制程序执行错峰脱水或反向配重，再完成脱水。

第一方面，本发明提供一种多筒洗衣机的协同控制方法，包括：检测大筒的偏心量与小筒的偏心量；根据大筒的偏心量与小筒的偏心量判断是否满足同时脱水条件；当不满足同时脱水条件时，按照协同控制程序执行错峰脱水或反向配重；执行错峰脱水或反向配重后，控制大筒与小筒完成脱水。

第二方面，本发明提供一种多筒洗涤设备，包括大筒、小筒、分水阀、分排水管路、共用减振组件和独立悬挂；大筒包括大筒内筒与大筒外桶，小筒包括小筒内筒与小筒外桶；分水阀经出水口分别与大筒外桶、小筒外桶连通；分排水管路的大筒排水管与小筒排水管分别连通大筒外桶底部与小筒外桶底部，相互隔离且互不串水；大筒与小筒各自通过独立悬挂悬挂；共用减振组件固定于机壳与独立悬挂之间，同时连接大筒的悬挂件与小筒的悬挂件。

与现有技术相比，本发明的有益效果在于：其一，分水阀与分排水管路使洗涤水分路、排水分路互不串水，外衣与内衣分开洗涤；其二，大筒与小筒各自独立悬挂，振动先经独立悬挂隔离，避免两筒刚性串联传振；其三，共用减振组件同时承接两筒悬挂件，配合协同控制程序的错峰脱水或反向配重，抑制两筒振动叠加引起的共振，降低整机位移量。

## 具体实施方式
下面结合附图对本发明的具体实施方式作详细说明。以下实施例用于说明本发明，但不用于限制本发明的范围。

实施例1
本实施例提供一种多筒洗衣机，大筒为滚筒式，用于洗涤外衣；小筒为波轮式，用于洗涤内衣。大筒内筒的内壁固定有提升筋，小筒内筒的内壁固定有提升筋；大筒外桶与小筒外桶的上部均固定有平衡环；大筒内筒与小筒内筒分别由直驱电机驱动转动，直驱电机与大筒内筒之间、直驱电机与小筒内筒之间分别设置有离合器。

水路结构：分水阀的进水口与外部进水管路连通，分水阀的两个出水口分别与大筒外桶和小筒外桶连通；分排水管路包括大筒排水管与小筒排水管，大筒排水管的上端与大筒外桶的底部连通，小筒排水管的上端与小筒外桶的底部连通，大筒排水管与小筒排水管相互隔离且互不串水。喷淋臂设置于小筒外桶的上部，由分水阀切换供水；浊度传感器设置于小筒外桶的底部，用于检测洗涤水浊度；软水树脂装填于盐箱内，盐箱经管路接入进水水路；热泵循环回路包括蒸发器与冷凝器，蒸发器与冷凝器分别布置于机壳背部；绒毛过滤器设置于小筒排水管的上游。

悬挂与减振结构：大筒通过独立悬挂悬挂于机壳内的安装梁上，小筒通过独立悬挂悬挂于大筒外桶的下方；共用减振组件固定于机壳与独立悬挂之间，同时连接大筒的悬挂件与小筒的悬挂件。共用减振组件包括减振弹簧、阻尼器与平衡配重块，减振弹簧的上端固定于机壳，减振弹簧的下端连接独立悬挂，阻尼器的两端分别铰接机壳与独立悬挂，平衡配重块滑动设置于共用减振组件的横向导轨上。独立悬挂包括大筒悬挂吊杆与小筒悬挂吊杆，大筒悬挂吊杆的上端固定于机壳的顶部，大筒悬挂吊杆的下端与大筒外桶的外壁铰接，小筒悬挂吊杆的上端固定于大筒外桶的底部加强筋，小筒悬挂吊杆的下端与小筒外桶的外壁铰接。

协同控制程序流程如图1所示：
S1、检测大筒的偏心量与小筒的偏心量；
S2、根据大筒的偏心量与小筒的偏心量，判断是否满足同时脱水条件；
S3、当不满足同时脱水条件时，按照协同控制程序执行错峰脱水或反向配重；
S4、执行错峰脱水或反向配重后，控制大筒与小筒完成脱水。

本实施例的负载条件为：大筒装载外衣5kg（示例值），小筒装载内衣3件（示例值）。水位与水量：大筒水位对应水量35L（示例值），小筒水位对应水量8L（示例值）。洗涤温度：大筒40℃，小筒30℃。脱水转速：大筒1200r/min，小筒800r/min。节拍与时间窗：错峰脱水的错峰时间窗取10s（示例值，取值范围8-15s）；预设偏心量阈值取100g·mm（示例值，取值范围80-120g·mm）；反向配重时小筒的偏心相位与大筒的偏心相位相差180°。脱水结束后，由浊度传感器的浊度变化与转速衰减进行判干，判干完成后进入漂洗阶段。

对照效果数据（示例值，在同一整机台架、相同负载条件下测得）：两筒同时脱水且无协同控制时，整机位移量为4.2mm；采用错峰脱水时，整机位移量为1.6mm；采用错峰脱水叠加反向配重时，整机位移量为2.1mm。同时脱水工况下两筒振动峰值叠加并接近整机共振区间，错峰脱水与反向配重使两筒振动峰值错开，整机位移量明显下降。

实施例2
本实施例与实施例1的区别在于参数取值：错峰时间窗取8s，预设偏心量阈值取80g·mm；大筒装载外衣8kg（示例值），小筒装载内衣5件（示例值）；大筒水量42L，小筒水量10L；洗涤温度大筒60℃、小筒40℃；脱水转速大筒1000r/min、小筒700r/min。其余结构、水路连接关系与协同控制程序与实施例1相同。

实施例3
本实施例与实施例1的区别在于：反向配重工况下，平衡配重块沿共用减振组件的横向导轨滑动，补偿大筒与小筒之间的偏心质量差；偏心量阈值取120g·mm，错峰时间窗取15s。其余结构、水路连接关系与控制流程与实施例1相同。

# 摘要
本发明公开一种多筒洗衣机的协同控制方法及多筒洗涤设备。大筒洗涤外衣、小筒洗涤内衣，分水阀与分排水管路使洗涤水分路、排水分路互不串水；大筒与小筒各自独立悬挂并由共用减振组件承接；协同控制程序检测两筒偏心量，判断同时脱水条件，不满足时执行错峰脱水或反向配重，抑制两筒同时脱水时振动叠加引起的共振与整机位移。
