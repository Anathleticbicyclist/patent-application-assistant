# 权利要求书

1. 一种运行状态异常检测方法，其特征在于，包括：
S1、采集目标设备的运行时序数据；
S2、对所述运行时序数据滑窗截取，提取表征设备状态的特征向量；
S3、将所述特征向量输入训练完成的检测模型，输出状态分类结果；
S4、当所述状态分类结果命中告警阈值时，输出异常告警。
2. 根据权利要求1所述的方法，其特征在于，所述检测模型为三层前馈神经网络，输入层维度与所述特征向量的维度一致，隐藏层神经元数为32，输出层为二分类节点。
3. 根据权利要求1所述的方法，其特征在于，所述滑窗的窗口长度为5-20个采样周期，步长为1个采样周期。
4. 根据权利要求2所述的方法，其特征在于，所述检测模型在训练时以标注为正常/异常的历史运行时序数据作为样本，样本规模为10000条。
5. 一种运行状态异常检测装置，包括数据采集单元（10）、特征提取单元（20）、模型推理单元（30）、告警输出单元（40）、处理器和存储器，其特征在于，所述处理器执行所述存储器中的程序时实现权利要求1至4任一项所述的方法。

# 说明书

## 技术领域
本发明涉及工业设备状态监测与人工智能算法领域，具体涉及一种基于时序数据的设备运行状态异常检测方法及装置。

## 背景技术
现有设备巡检多依赖人工定期读取仪表读数，难以及时捕捉早期异常；基于固定阈值的告警方案对工况波动敏感，误报较多。通用识别模型直接套用振动信号，未结合设备运行时序数据的相邻相关性，在样本有限时识别准确率不足。对比文件 CN________A（占位号，示例用，交付前须替换为真实检索到的对比文件公开号）公开了一种固定阈值告警方案，仅对单点越限进行告警，未做滑窗特征提取与模型分类。

## 发明内容
本发明要解决的技术问题是：如何在有限标注样本条件下，从设备运行时序数据中识别早期异常状态，并降低工况波动引起的误报。

为解决上述技术问题，本发明提供一种设备运行状态异常检测方法：滑窗截取运行时序数据并提取特征向量，输入检测模型输出分类结果，命中告警阈值时输出异常告警。

第一方面，本发明提供一种设备运行状态异常检测方法，包括：采集目标设备的运行时序数据；对运行时序数据滑窗截取，提取表征设备状态的特征向量；将特征向量输入检测模型，输出状态分类结果；命中告警阈值时输出异常告警。

第二方面，本发明提供一种运行状态异常检测装置，包括数据采集单元（10）、特征提取单元（20）、模型推理单元（30）和告警输出单元（40），还包括处理器和存储器，处理器执行存储器中的程序时实现上述方法。

与现有技术相比，本发明的有益效果在于：其一，滑窗特征向量保留了相邻采样点的相关性，对早期缓变异常更敏感；其二，检测模型在有限标注样本下即可训练，告警阈值基于分类概率判定，相对固定单点阈值降低了工况波动引起的误报。

## 具体实施方式
下面结合附图对本发明的具体实施方式作详细说明。以下实施例用于说明本发明，但不用于限制本发明的范围。

实施例1

### 算法流程
图1示出本实施例的方法流程：S1 由数据采集单元（10）采集目标设备的运行时序数据；S2 由特征提取单元（20）对运行时序数据滑窗截取，提取表征设备状态的特征向量；S3 由模型推理单元（30）将特征向量输入检测模型，输出状态分类结果；S4 由告警输出单元（40）在状态分类结果命中告警阈值时输出异常告警。

### 模型结构与参数含义
检测模型为三层前馈神经网络。输入层维度与特征向量的维度一致，本实施例特征向量取均值、方差、斜率、峰值四个统计量，故输入层维度为4；隐藏层神经元数为32，采用 ReLU 激活函数；输出层为二分类节点，输出正常与异常两类的概率。特征向量各分量含义：均值表征时段内信号平均水平，方差表征信号波动程度，斜率表征变化趋势，峰值表征瞬时冲击强度。

### 训练数据来源与规模
检测模型在训练时以标注为正常/异常的历史运行时序数据作为样本，样本规模为10000条；样本来自厂区三台同款电机连续三个月的运行日志，由运维人员标注正常与异常，训练集与验证集按8:2划分。

### 运行环境
模型推理部署于边缘网关，内存2GB，单条时序片段的推理时延小于100ms；数据采集单元（10）、特征提取单元（20）、模型推理单元（30）和告警输出单元（40）以软件模块形式加载于该网关。

### 技术场景与技术数据
本实施例绑定工业电机轴承监测场景，处理的技术数据为轴承温度与振动的运行时序数据，采样周期为100ms。本实施例的状态异常检测装置中，数据采集单元（10）按采样周期采集运行时序数据；特征提取单元（20）滑窗截取并提取特征向量；模型推理单元（30）加载检测模型输出状态分类结果；告警输出单元（40）在命中告警阈值时输出异常告警。本实施例窗口长度取20个采样周期，步长为1个采样周期；告警阈值取异常概率0.8，即状态分类结果给出的异常概率大于0.8时输出异常告警。

实施例2
本实施例与实施例1的区别在于：隐藏层神经元数为16，窗口长度取5个采样周期；其余步骤、模型结构与训练数据划分方式与实施例1相同。该参数组合适用于采样周期更短、数据量更小的边缘节点。

本发明公开一种设备运行状态异常检测方法及装置。该方法采集目标设备的运行时序数据，滑窗截取并提取特征向量，将特征向量输入检测模型输出状态分类结果，命中告警阈值时输出异常告警。本发明在有限标注样本条件下识别设备早期异常状态，并降低工况波动引起的误报。
