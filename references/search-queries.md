## 二、检索式构造（四步法）

### 第 1 步：抽概念词（不是抽句子）

从 FEAT 表里挑 3–5 个「不可替代」的名词：
- 对象词（做什么东西）：如「电池包」「光模块」「对账」
- 动作词（怎么做的）：如「二次确认」「断点续传」「插值」
- 效果/问题词（解决什么）：如「误报」「功耗」「时延」

### 第 2 步：扩词（每个概念至少 4 个表达）

| 类型 | 示例（以「误报抑制」为例） |
|---|---|
| 同义 | 误报 / 误触发 / 虚警 / false alarm / false positive |
| 上位 | 异常检测 / 告警处理 / anomaly detection |
| 下位 | 阈值判定 / 二次确认 / 双人复核 |
| 行业口语 | 抖动、毛刺、闪断 |
| 英文变体 | spurious trigger / nuisance alarm / false detection |

中国申请人常用「……的方法、装置、系统、设备及存储介质」的题名格式，可专门用 `TI=(方法 AND 装置)` 缩小范围。

### 第 3 步：加分类号（把检索范围从「词」拉回「领域」）

| 领域 | IPC / CPC 主分类 |
|---|---|
| 人工智能 / 机器学习 | G06N 3/*、G06N 20/*、G06F 18/* |
| 数据处理 / 软件实现 | G06F 9/*、G06F 16/*、G06F 40/* |
| 商业方法 / 管理（易被客体驳回） | G06Q 10/*、G06Q 30/*、G06Q 40/* |
| 通信 | H04L 12/*、H04L 41/*、H04W 4/*、H04W 24/* |
| 图像 / 视觉 | G06T 7/*、G06V 10/*、G06V 20/* |
| 电池 / 电驱动 | H01M 10/*、B60L 58/*、H02J 7/* |
| 半导体 / 器件 | H01L 21/*、H01L 29/* |
| 控制 / 工业 | G05B 19/*、G05B 23/* |
| 医疗 / 诊断 | A61B 5/*、A61B 34/* |
| 化学 / 材料 | C07D、C08L、C09K、B32B |
| 外观设计 | Locarno 分类（如 14-02 电子设备） |

分类号用法：`(关键词) AND IPC=(G06F16/00 OR G06N20/00)`；拿不准就用「关键词命中后，看结果里出现频次最高的分类号」再回检一次（迭代式检索）。

### 第 4 步：三套检索式，逐层收窄

```
S1 查全（宽）：(对象词 OR 同义) AND (动作词 OR 同义)
S2 查准（窄）：S1 AND IPC=(领域分类) AND (效果词)
S3 查人（定向）：申请人/发明人 + 技术词（追竞品与重点对手的在先布局）
```

每套都要记录命中数量；S1 命中过万说明词太宽，S2 命中为 0 说明分类号用错或词选窄了——两种都要调整后重跑，**不要拿 0 结果当「没有现有技术」**。

## 三、检索记录表（必须交付，保证可复现）

| # | 数据源 | 检索式（原样粘贴） | 限定条件（时间/国别/法律状态） | 命中数 | 筛后保留 | 备注 |
|---|---|---|---|---|---|---|
| 1 | CNIPA | `TI=(误报 AND 抑制) AND IPC=(G06F18)` | 2015-01-01 至今，中国 | 137 | 6 | — |
| 2 | Google Patents | `("false alarm" OR "false positive") AND (suppress OR reduce) AND battery` | 全球，含中文 | 1,204 | 4 | 英文表达更全 |
| 3 | Espacenet | `CPC=G01R31/367 AND "thermal runaway"` | 全球 | 312 | 3 | 同族已合并 |

**必写的一句话局限说明**：例如「仅检索中英文库，未覆盖日韩原文；未检索非专利文献中的企业内部标准」。这句能救你——检索不可能是穷尽的，说明边界比假装穷尽专业得多。

## 四、对比文件相关性分级

| 等级 | 定义 | 用法 |
|---|---|---|
| A | 同一技术问题 + 大部分特征重合，可能破坏新颖性 | 必须逐特征比对，写进报告正文 |
| B | 同领域、部分特征重合，影响创造性 | 作为「最接近现有技术」候选 |
| C | 跨领域但手段相同，可作技术启示 | 用于创造性第三步 |
| D | 仅背景相关 | 只进附录 |

每篇至少摘 3 个字段：**公开号、公开日、相关段落原文（要引用，不要转述）**。相关段落是后面答复审查意见时的弹药。

## 五、特征比对表（新颖性/侵权通用）

| 权项特征 | 对比文件 D1 对应内容（段落号/原文） | 是否公开 | 差异 |
|---|---|---|---|
| F1 采集单元，100Hz | 段[0021]「采样频率 50–200Hz」 | 是（范围覆盖） | 无 |
| F3 阈值+二次确认 | 段[0035]「超过阈值直接告警」 | 否 | 缺少二次确认 |
| F4 断点续传 | 未记载 | 否 | 无 |

结论格式：`权项 1 与 D1 的区别特征为 F3、F4；其中 F3 带来「降低误报」效果，D1–D3 均未给出相同作用的技术启示 → 具备创造性（初判）`。
