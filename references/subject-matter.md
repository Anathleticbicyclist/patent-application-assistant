# 分领域客体适格性与撰写要点

中国专利法第 25 条排除「智力活动的规则和方法」等客体。不同领域的「能不能申请」「怎么写才不被驳」差别很大，别用一套模板套所有行业。

用法：P1 结构化之后、P6 撰写之前，按领域读对应一节，确认三件事——**是否属于可授权客体、技术特征够不够、实施例撑不撑得住**。

---

## A. 软件 / 算法 / AI

**核心判据**（审查指南第二部分第九章）：权利要求必须解决**技术问题**、采用**技术手段**、获得**技术效果**。算法本身是数学方法，只有与具体技术领域结合、处理的是技术数据、输出的是技术结果，才可能授权。

自检三问：

1. 这份方案解决的是**技术问题**（性能、功耗、精度、稳定性、资源占用）还是**业务问题**（怎么收费、怎么排班、怎么推荐更赚钱）？→ 后者大概率客体不适格。
2. 处理的是**技术数据**吗？（传感器信号、图像、语音、控制参数、设备状态 —— 是；用户偏好、订单金额、文本语义 —— 通常不是）
3. 输出的是**技术结果**吗？（控制指令、设备参数、图像增强结果 —— 是；一个评分、一个推荐列表 —— 通常不是）

**撰写要点**

- 权项里必须有硬件/系统落脚点：「一种……方法，应用于包括存储器和处理器的电子设备」或「由传感器采集……」；
- 每个算法步骤写清**输入是什么数据、怎么处理、输出什么**，不要只写「通过神经网络模型预测」；
- 训练方法与使用方法**分开写权项**（训练数据、损失函数属于技术方案的一部分，但纯训练策略可能被视为非技术）；
- 避免纯功能性表述（「智能地」「自适应地」），要落到可执行的步骤；
- 说明书里必须有**至少一个完整实施例**的算法流程 + 参数取值，否则权项概括没有支持（第 26 条第 4 款）。

**常见驳回**：「权利要求 1 请求保护的方案未采用技术手段解决技术问题，属于专利法第 25 条第 1 款第（二）项规定的智力活动的规则和方法」。

## B. 商业方法 / 交互 / UI

- 纯商业模式（收费规则、分成比例、营销策略）→ 不授权；
- **带技术手段的**（支付安全校验、库存调度与设备联动、交互过程中的数据处理）→ 可以，但技术特征要写足；
- UI 交互：发明保护「交互方法 + 数据处理」，**外观设计**保护「图形用户界面」（需产品载体 + 静态图，动态 GUI 要提交变化过程图）；
- 常见错误：把「用户点了 A 就展示 B」写成权项，缺少数据来源与处理，被判为「人为规定」。

**判断**：把方案里所有「人做的决策」换成「系统自动执行」，如果剩下的仍然只是「按规则分发信息」，客体就悬。

---

## C. 机械 / 结构

客体几乎不构成障碍，**驳回集中在必要技术特征缺失与支持不足**。

- 独立权利要求必须包含**解决技术问题所必需的全部必要技术特征**：部件 + **连接关系** + **位置关系** + 必要的形状/材料；
- 「连接」必须写清是固定连接、转动连接、滑动连接、一体成型、螺纹连接 —— 只写「连接」会被认为不清楚（第 26 条第 4 款）；
- 附图与文字必须一一对应，同一部件全文同一标记、同一名称；
- 尺寸、角度、材料如果用「约」「大致」→ 直接踩不确定用语；
- 实施例：至少给一个完整结构 + 一个变形例，否则从权的「替换结构」没有支持。

**自检**：把独权画成一张装配图，图上每个部件都能在权项文字里找到，且每条连线都有对应的连接关系描述。

---

## D. 电子 / 通信 / 芯片

- 电路类：模块 + 信号流向 + 时序关系，避免只堆功能模块名（「获取模块、判断模块、输出模块」会被认为功能性限定过宽）；
- 通信类：协议流程要写清**消息名称、发送方/接收方、触发条件、字段含义**；只写「协商」「同步」不够；
- **标准必要专利（SEP）**：若方案将被写入 3GPP/IEEE 等标准，需在提案阶段就做**声明（declaration）**，并注意 FRAND 承诺；这属于商业与法律动作，本技能只能提示、不能代办；
- 芯片/工艺类：结构 + 工艺步骤分别申请；工艺参数范围要有端点与中间值实施例。

**提示**：通信领域的对比文件极多，创造性论证必须落到「具体的协议改进带来的技术效果」，不能只说「提高了效率」。

---

## E. 医药 / 生物

- 客体一般没问题，**驳回集中在充分公开与实验数据**；
- 说明书必须公开**如何制备、如何使用、如何验证效果**；药物权利要求需要**实验数据证明技术效果**（不能只描述机理）；
- **补充实验数据**：审查指南允许申请后补充，但前提是原申请文件里**已记载了相应技术效果**、补充数据是用来说明该效果的。所以交底书阶段就要把关键实验数据写进去，别留到答复时再补；
- 生物材料需**保藏**并提供保藏证明；涉及序列表的按 WIPO 标准 ST.26 提交；
- 抗体/序列类：功能限定 + 序列结构要匹配，避免「一种能结合 X 的抗体」这种纯功能限定。

**自检**：把实施例的数据表拿出来，问一句「不看这些数据，审查员能相信效果吗？」

---

## F. 化学 / 材料

- **马库什权利要求**：通式 + 取代基定义，所有变量都要有定义，且说明书要支持每个变量的取值；
- **数值范围**：写明端点，且实施例覆盖端点与中间值；只给一个点、权项却要一个区间 → 支持不足；
- **参数**：测量方法必须写清（用什么仪器、什么条件），否则参数无意义；
- 组合物：组分 + 含量范围 + 作用，含量单位统一。

**常见驳回**：「权利要求概括的范围过大，说明书仅给出少数几个具体化合物，无法支持」。

---

## 跨领域共性检查（写进 P8 质检）

1. 权项里的每个技术术语，说明书里都能找到定义或实施例；
2. 权项的每个「上位概括」，至少有一个下位实施例支撑；
3. 效果与技术特征有因果链（因为 A 所以 B），不是并列罗列；
4. 实施例之间必须有**实质差异**（参数、结构、路径），只改数值不算不同实施例。
