# P0 合规闸门（开工前必须问完，问不完就别往下走）

技术方案能写，不代表能申请。这一页解决「先决条件」问题——**判断错了，后面写得再好也是白写，甚至有害**。
每一项都给「怎么问」和「答错会怎样」，不做抽象说教。

---

## 一、谁能申请：权属

| 情形 | 规则 | 你要问用户 |
|---|---|---|
| 员工在职、用公司资源完成 | **职务发明**，申请权归单位（专利法第 6 条） | 「这个方案是你个人想的，还是职务工作中做的？用没用公司的设备/数据/经费？」 |
| 主要利用单位物质技术条件完成 | 归属由**合同约定**，没约定归单位 | 「有没有和公司签过发明归属协议？」 |
| 两家公司/高校合作开发 | 有约定从约定；无约定归**共同**完成方（第 8 条） | 「有没有合作开发协议？里面写了成果归属吗？」 |
| 甲方委托乙方开发 | 同上，无约定归**受托方**（完成方） | 「委托开发合同里成果条款怎么写的？」 |

**为什么必须先问**：权属错了，签了转让/许可也无效，后续融资尽调会被打回。个人申请而实际是职务发明的，单位可主张权利，甚至构成侵占。

产出要求：交底书首页写明「申请人：___；权属依据：职务发明/合同约定/个人」。

---

## 二、能不能公开：新颖性宽限期（6 个月，情形受限）

首次公开后 **6 个月内**，且**仅限**专利法第 24 条的四类情形，才不丧失新颖性：

1. 在国家出现紧急状态、非常情况下，为公共利益目的首次公开；
2. 在中国政府主办或承认的**国际展览会**上首次展出；
3. 在**规定的学术会议或技术会议**上首次发表；
4. 他人未经申请人同意而泄露其内容。

**最容易踩的坑**：公司发布会、客户演示、产品上线、公众号推文、GitHub 开源、论文预印本 —— **这些都不在第 24 条里，是普通公开，直接毁掉新颖性**。

| 你要问 | 判断 |
|---|---|
| 「方案有没有对外说过？上线、演示、发论文、开源、给客户看过？」 | 有 → 追问**日期**与**形式** |
| 「日期距今多久？」 | 超过 6 个月 → 新颖性已失，只能改方案或找改进点 |
| 「是什么场合？」 | 非第 24 条四类 → **即使 6 个月内也算公开** |

结论必须写清：「已于 YYYY-MM-DD 以 ___ 方式公开，属于/不属于第 24 条情形，新颖性风险：高/中/低」。

## 三、能不能出国申请：保密审查（这条漏了后果极重）

**在中国完成的发明或实用新型，向外国申请专利前，必须先报国务院专利行政部门做保密审查**（专利法第 19 条）。

- 违反的后果：该发明/实用新型**在中国申请专利时不予授权**（不是罚款，是直接拿不到中国专利）。
- 适用范围：发往境外母公司/境外律所/直接提交外国申请，都算「向外国申请」。
- 外观设计**不适用**保密审查。
- 实操：可在提交外国申请前请求，也可与外国申请同时提出；已在国内申请的，可在申请时一并请求。

**你要问**：「这个方案有没有可能去美国/欧洲/日本申请？发明是在中国完成的吗？」
有 → 在交付物里加一条「**境外申请前须先办保密审查**」，并列出时限。

## 四、数据能不能出境：技术方案的保密

交底书里常有未公开的配方、参数、客户数据、源代码。把它交给**境外托管的 API / MCP 服务**（Patsnap 海外节点、PQAI 海外部署、海外 LLM）等于把技术秘密发出去。

| 动作 | 风险 | 处理 |
|---|---|---|
| 把完整交底书贴给境外 API 做检索 | 技术秘密外泄，且可能触及数据出境合规 | 先脱敏：去掉配方比例、客户标识、核心参数，只留检索必需的技术特征 |
| 把含个人信息的实施例（病历、用户行为）外发 | 个人信息出境 | 去标识化，或改用本地部署 |
| 用企业内部系统处理 | 相对可控 | 优先本地/内网 |

**默认做法（写进流程）**：检索阶段只发**检索式与上位化描述**，不发交底书原文；需要发原文时先经用户确认。

## 五、申请策略：单一性、分案、优先权、时限

### 5.1 单一性（专利法第 31 条）

一件申请只限一项发明；属于**一个总的发明构思**的两项以上发明可以合并申请。判断看「是否共享同一个或相应的**特定技术特征**」。

- 一个方案里塞了 3 个互不依赖的发明点 → 强行合案会被要求分案，审查周期拖长；
- 建议在 P2 保护点挖掘时就分好：「一案多权项」还是「拆成 N 件」。

### 5.2 分案

时机：母案授权办理登记手续期限内、被驳回后 3 个月内、或审查员要求时。
用途：把从权提升为独立保护、保留未写入权项的技术内容、应对单一性驳回。

### 5.3 优先权与关键时限

| 事项 | 期限 | 备注 |
|---|---|---|
| 外国优先权（发明/实用新型） | 首次申请起 **12 个月** | 外观设计 **6 个月** |
| 本国优先权 | 12 个月 | 可多次，但有限制 |
| PCT 进入中国国家阶段 | 优先权日起 **30 个月** | 可请求宽限（有费用） |
| 答复审查意见 | 通知书**指定期限**（首次 OA 常见 4 个月） | 可请求延期，逾期视为撤回 |
| 申请费/实质审查请求 | 申请日起 3 年内提实审 | 逾期视为撤回 |

**纪律**：交付物里凡是提到时限，都写「以通知书指定期限为准，此处为常见值」，不要拍死具体天数。

### 5.4 抵触申请（新颖性的一部分）

申请日以前他人提出、申请日以后（含当日）公布的同样申请，破坏新颖性（专利法第 22 条第 2 款）。**这类文献在公开库检索时看不到**，只能靠「同族/同申请人近期申请」的侧面排查。

检索报告里必须单列一句：「已排查抵触申请风险：无法穷尽，建议申请前做同族与在审申请核查」。

## 六、诚信底线（专利法第 20 条）

- 不得提交**非正常申请**（编造、拼凑、明显抄袭现有技术、无实际研发的批量申请）；
- 不得伪造实验数据、实施例、对比效果；
- 不得为规避审查而故意拆分/改写成无技术意义的方案。

这三条写进技能的三条底线里，属于「用户要求也不能做」的范畴。
